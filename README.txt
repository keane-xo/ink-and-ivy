INK AND IVY — FEATURED COVERS + NOTES

The featured-books section now uses a large editorial side-by-side layout.

Each featured pick shows:
- The actual book cover prominently on the left
- The book title and author on the right
- Your personal "why I picked it" note directly beside the cover
- Small genre/page-count/availability details below
- An Open Book button

On phones the cover stacks above the note so everything stays readable.
