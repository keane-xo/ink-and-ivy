INK AND IVY — LIBRARIAN NAME BADGE

This adds a permanent special role badge reading:

librarian

It appears next to the librarian/admin reader's name throughout the reader-facing site:
- public profile
- community posts
- community comments
- community chat
- reader directory
- reader account/profile preview
- Friend Picks

The badge is tied to the librarian/admin UID, so other readers do not receive it.
It is separate from Storykeeper / Ink Society / Keeper of the Stacks, so the
librarian can still choose and display an earned reading title too.

UPLOAD AND REPLACE THESE FILES IN GITHUB:
- profile.html
- profile.css
- profile.js
- community.css
- community.js
- reader.html
- reader.css
- reader.js
- recommendations.css
- recommendations.js
